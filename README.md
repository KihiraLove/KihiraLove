## Kihira's Toolkit
Kihira's Toolkit [(website)](https://kihiralove.github.io/kihiras-toolkit/) [(repo)](https://github.com/KihiraLove/kihiras-toolkit) is a group of OSRS related tools written in JavaScript and hosted on GitHub Pages.  
Its component are:
- OSRS Boss Loot Simulators [(website)](https://kihiralove.github.io/osrs-boss-loot-simulators/) [(repo)](https://github.com/KihiraLove/osrs-boss-loot-simulators) a loot simulator and dry calculator.
- Slayer Blocks [(website)](https://kihiralove.github.io/slayer-blocks/) [(repo)](https://github.com/KihiraLove/slayer-blocks) a slayer blocklist planner.
- Bingo Player Stats [(website)](https://kihiralove.github.io/bingo-player-stats/)[ (repo)](https://github.com/KihiraLove/bingo-player-stats) a tool to quickly gather players stats into an spread sheet.
- OSRS Optimal Quest Guide (WIP) [(repo)](https://github.com/KihiraLove/osrs-optimal-quest-guide) a computer optimised quest route.
- Kihira's tools common  [(repo)](https://github.com/KihiraLove/kihiras-tools-common) shared style and moduls for all tools.

## Clan collection log and components
Clan Clog [(repo)](https://github.com/KihiraLove/clan-clog) is a self hostable OSRS clan shared collection log and event tracker, made with NodeJs and React, 
its Submissions API collects data from the accompanying  
[RuneLite API client](https://github.com/KihiraLove/clan-clog-client) that gathers game data automatically and submits it. Or manually with the built in discord bot.  
There is also a [manual API client/ API tester](https://kihiralove.github.io/clan-clog-submitter/) [(repo)](https://github.com/KihiraLove/clan-clog-submitter) hosted on GitHub Pages.

## RuneLite plugins
- Big Pets [(repo)](https://github.com/KihiraLove/big-pets) [(PluginHuh)](https://runelite.net/plugin-hub/show/big-pets) lets you resize your followers by changing the rendering pipeline.
- Racecar [(repo)](https://github.com/KihiraLove/racecar) [(PluginHuh)](https://runelite.net/plugin-hub/show/racecar) lets you switch out your Dom pet to the Burrowed Doom model by changing the rendering pipeline.
- Puppy Finder [(repo)](https://github.com/KihiraLove/puppy-finder) [(PluginHuh)](https://runelite.net/plugin-hub/show/puppy-finder) helps you find the wandering dogs after A Ruff Situations
  The following plugins were never released and probably never will be:  
- Gauntlet Locker [(repo)](https://github.com/KihiraLove/gauntlet-locker) disables the gauntlet portal and plays some animation when you try to access it anyway.
- Raid Logs [(repo)](https://github.com/KihiraLove/raid-logs) logs your and your parties raid performance.
- OSRS Jokes [(repo)](https://github.com/KihiraLove/osrs-jokes) this is just silly (puts a bunch of joke cards into the game)
